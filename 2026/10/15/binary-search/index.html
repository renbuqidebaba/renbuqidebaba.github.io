二分查找

DATA STRUCTURES · PROBLEM SOLVING

二分不只是「在有序数组里找数」。只要答案具有单调性——某个条件在分界点一侧成立、另一侧不成立——就可以二分。

这一篇整理了二分查找的几种写法和边界处理，都是实际做题时最容易写错的地方。

二分查找时区间的左右端取开区间还是闭区间在绝大多数时候都可以。第一是尝试熟练使用一种写法，比如左闭右开（满足C++、Python 等语言的习惯）或左闭右闭（便于处理边界条件），尽量只保持这一种写法；第二是在刷题时思考如果最后区间只剩下一个数或者两个数，自己的写法是否会陷入死循环，如果某种写法无法跳出死循环，则考虑尝试另一种写法。（进行二分的时候，区间要更新到mid的下一位！！）

Leetcode 34 查找区间 mid (找第一个和最后一个)

对着小蓝书，这个题目说实话自己一开始没有看懂，到现在终于搞懂了！没有什么是搞不懂的就是看自己画不画时间！

力扣解释：考虑 target 开始和结束位置，其实我们要找的就是数组中「第一个等于 target 的位置」（记为 leftIdx）和「第一个大于 target 的位置减一」（记为 rightIdx）。二分查找中，寻找 leftIdx 即为在数组中寻找第一个大于等于 target 的下标，寻找 rightIdx 即为在数组中寻找第一个大于 target 的下标，然后将下标减一。两者的判断条件不同，为了代码的复用，我们定义 binarySearch(nums, target, lower) 表示在 nums 数组中二分查找 target 的位置，如果 lower 为 true，则查找第一个大于等于 target 的下标，否则查找第一个大于 target 的下标。

class Solution {
public:
    int search(vector<int>& nums, int target) {
        // 返回第一个查询到的target下标，画个图
        int l = 0, r = nums.size() - 1, mid;
        while (l <= r) {
            mid = l + (r - l)/2;
            if (nums[mid] < target) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return l;
    }
    int search2(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1, mid;
        while(l <= r) {
            mid = l + (r - l)/2;
            if (nums[mid] <= target) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        return l;
    }
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.size() == 0) return vector<int> {-1, -1};
        int left = search(nums, target);
        int right = search2(nums, target) - 1;
        if (left == nums.size() || nums[left] != target) return vector<int> {-1, -1};
        return vector<int> {left, right};
    }
};

Leetcode 162 寻找峰值 mid（区间不有序二分）

判断一下只有一个的情况，以及峰值在两边的情况。

如果都不在，就开始二分区间。

class Solution {
public:
    int findPeakElement(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return 0;
        if (nums[0] > nums[1]) return 0;
        if (nums[n-1] > nums[n-2]) return n-1;
        int l = 1 , r = n - 2, mid = 0;
        while(l <= r) {
            mid = l + (r - l)/2;
            if (nums[mid] > nums[mid - 1] &&  nums[mid] > nums[mid + 1]) return mid;
            else if (nums[mid] > nums[mid - 1]) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
};

Leetcode 81 搜索旋转排序数组II mid

leetcode101思路：其实就是一直对于区间进行二分，在区间有序的时候进行二分查找。如果区间是无序的，就需要找到下一个有序的区间。感觉还是没有深入去理解过，因为现在又不记得了

class Solution {
public:
    bool search(vector<int>& nums, int target) {
        int l = 0, r = nums.size() - 1;
        while(l <= r) {
            int mid = l + (r - l)/2;
            if (nums[mid] == target) return true;
            if (nums[mid] == nums[l]) l++;
            else if (nums[mid] == nums[r]) r--;
            else if (nums[mid] < nums[r]) {
                if ( target > nums[mid] && target <= nums[r]) {
                    l = mid + 1;
                } else {
                    r = mid - 1;
                }
            } else if (nums[mid] > nums[l]) {
                if ( target < nums[mid] && target >= nums[l]) {
                    r = mid - 1;
                } else {
                    l = mid + 1;
                }
            }
            
        }
        return false;
    }
};

Leetcode 33 搜索旋转排序数组 mid

之前用二分查找的前提是需要有序。这个题目是部分有序的空间的，照样用二分的思路。

思路：

判断target和nums[mid]是不是在同一个有序段内：利用数组最后一个元素进行判断。

不在同样一个段内也去二分缩小空间。如果在一个有序段内，那就直接用二分找了。

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        n = len(nums)
        i, j = 0 , n - 1
        while i <= j:
            mid = (i + j) // 2
            # 说明target和x不在一个递增段
            if target > nums[j] >= nums[mid]:
                j = mid - 1
            elif target <= nums[j] < nums[mid]:
                i = mid + 1
            elif target < nums[mid]:
                j = mid - 1
            elif target > nums[mid]:
                i = mid + 1
            elif target == nums[mid]:
                return mid
        return -1

Leetcode 35 搜索插入的位置easy

这个题目就是二分查找的体现，自己还是习惯写闭区间（注意闭区间的话，判断条件应该是i <= j）。

最后的位置的判断的话，一开始直接返回mid + 1其实思路上没有问题，但是mid最后一次没有更新为最新的i，j的值。所以对于边线条件比如1234找0，这个就不对。所以最后要单独计算一次。

看了两年前自己写的东西：返回j + 1就是答案。不需要再算一次mid。

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        n = len(nums)
        i, j = 0, n - 1
        while i <= j:
            mid = (i + j) // 2
            if nums[mid] == target:
                return mid
            elif nums[mid] > target:
                j = mid - 1
            else:
                i = mid + 1
        return j + 1
