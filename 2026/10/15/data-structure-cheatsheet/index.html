堆结构

https://blog.csdn.net/t949500898/article/details/120177452

//要有一个导包container/heap


//继承接口后进行重写
type hp[]int
func (h hp) Len() int {
    return len(h)
}
//最大堆和最小堆的实现只有Less函数的区别，其他都是一样的。
func (h hp) Less(i, j int) bool{
    return h[i] < h[j]
}

func (h hp) Swap(i, j int) {
    h[i], h[j] = h[j], h[i]
}
func (h *hp) Push(v interface{}) {
    *h = append(*h, v.(int))
}
//pop操作会先交换第一个节点和最后的节点，所以最后的节点才是最小的
func (h *hp) Pop() interface{} {
    a := *h 
    v := a[len(a) - 1]
    *h = a[:len(a) - 1]
    return v
}

排序函数

Python 3 里“排序”只有两套工具。

# 内置函数：sorted(iterable, *, key=None, reverse=False)

不破坏原数据，返回新列表

任何可迭代对象（列表、元组、集合、生成器、字典视图…）都能用

key 只写“按什么比”，不写 cmp（Python 3 已废掉 cmp 参数）

nums = [5, 1, 3, 2]
new_nums = sorted(nums)                    # 默认升序
new_nums = sorted(nums, reverse=True)      # 降序

words = ['Python', 'go', 'Rust']
sorted(words, key=str.lower)               # 忽略大小写
sorted(words, key=len)                     # 按长度
sorted(words, key=lambda x: (len(x), x))   # 长度优先，再字典序
列表原地排序 list.sort(...)

Python 的 set 只能存放“可哈希（hashable）”的对象，而list 是可变对象，默认不可哈希，所以当你把列表 [num[i], num[j], num[k]] 直接塞进 set 时，解释器抛出TypeError: unhashable type: ‘list’。解决思路：把列表转换成不可变的等效结构，最常见的是用 tuple。

lt 是 Python 的数据模型钩子（dunder method），对应内置操作符 <。当你写 a < b 时，解释器会尝试去调：a.__lt__(b)，如果 a 所属的类型没有定义 lt，就会再反过来调b.__gt__(a)。都没有就会报错。为要把 ListNode 实例直接塞进 heapq，而 heapq 内部需要比较大小，于是需要补一个lt。
lambda a, b: a.val < b.val 是一个匿名函数，等价于：
Pythondef __lt__(self, other):

python踩坑：

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        s = 0
        self.dfs(root, s)
        return root

    def dfs(self, root, s):
        if root == None:
            return
        self.dfs(root.right, s)
        s += root.val
        root.val = s
        self.dfs(root.left, s)
问题在于 Python 的整数是不可变对象，函数参数传递的是值拷贝（对不可变对象而言）。在 dfs 方法中执行 s += root.val 时，只是创建了一个新的局部变量 s，并不会影响到外部的 s。
mmap[s[i]] += 1 当 s[i] 第一次出现时，字典里没有这个键，直接 += 会抛出 KeyError。
