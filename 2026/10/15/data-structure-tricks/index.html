单调栈解决「找左右两边第一个比它大/小的元素」，单调队列解决「滑动窗口极值」，Trie 解决「前缀匹配」。这几样东西模板性很强，背下来就能套。

Acwing 830 单调栈 模板

什么是单调栈：栈按照先进后出的次序保持是单调增或者减。单调栈是记录目前下一个比他小或者比他大的数。

在本题目中，一个栈的栈顶存储的一定是第一个比该元素小的值。

#include<iostream>
#include<stack>
#include<cstring>

int n;

int main() {
    scanf("%d", &n);
    stack<int> st;
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        while (st.size() && st.top() >= x) st.pop();
        if (!st.size()) printf("-1 ");

        st.push(x);
    }
    return 0;
}

Leetcode hot 84 柱状图中最大矩形 hard 单调栈

这题一开始拿到时候就是完全没有任何思路，看了答案后整理出来思路。用单调栈的思想，但是没有加哨兵，在处理边界条件有点问题。

思路：

对于每一个i对应高度可以组成的最大面积是什么了，取决于该高度的左右第一个小于他的高度。因为小于他就会拉低整个构成的矩形高度。

对于第一个小于这样的情况，我们应该去采用单调栈的方法来解决问题。记录每一个高度左右情况。最后遍历取得max就是答案。

栈中存放的是什么了？高度还是下标？ 很显然是下标，因为我们不仅要算高度还要算宽度，记录下标两个都可以很方便算出来。

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        n = len(heights)
        # 对于一个高度来说，应该是找左边和右边第一个比他小的数，第一个想到单调栈
        left = [-1]*n
        right = [n]*n
        st = []
        # 从左往右
        for i in range(0, n):
            while len(st) and heights[st[-1]] >= heights[i]:
                st.pop()
            if st:
                left[i] = st[-1]
            st.append(i)
        # 从右往左
        st = []
        for i in range(n - 1, -1, -1):
            while len(st) and heights[st[-1]] >= heights[i]:
                st.pop()
            if st:
                right[i] = st[-1]
            st.append(i)
        # 最后开始算每一个最大面积
        ans = 0
        for i in range(n):
            ans = max(ans, heights[i]*(right[i] - left[i] - 1))
        return ans

Leetcode 739 每日温度 mid 单调栈

这个题目就是典型的单调栈的题目。单调栈很早就训练了，但是还是忘记了，现在开始回顾一下。

单调栈是记录目前下一个比他小或者比他大的数。

操作的步骤是：

遍历栈去掉比自己大的数

判断是否为空，为空说明没有，不为空栈顶的元素就是

把新的元素压入栈中

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        st = []
        for i in range(n - 1, -1, -1):
            while st and temperatures[st[-1]] <= temperatures[i]:
                st.pop()
            
            if st:
                ans[i] = st[-1] - i

            st.append(i)
        return ans

Leetcode 239 滑动窗口的最大值 hard 单调队列 区间极值

纯暴力：维护一个队列，每次出对头，入队尾，然后取max存入答案。

单调队列的思路：1.队列是递减的，也就是队头是最大的，队尾是最小的。每次入新元素看看是否大于队尾，大于出队小于不管；看看队头是否超范围，超了出队，不超不管。记录答案的前提应该是满足正常的范围，至少k个进行统计。

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        ans = []
        mq = deque()
        for i in range(n):
            # 入
            while mq and nums[mq[-1]] <= nums[i]:
                mq.pop() # 维护q的单调性，大的才入队
            mq.append(i) # 注意保存的是下标，方便判断
            # 出
            left = i - k + 1 #算应该出队的下标
            if mq[0] < left:
                mq.popleft() #说明是之前的应该出队
            if left >= 0:
                ans.append(nums[mq[0]])
        return ans

LeetCode 155 最小栈 mid 两个栈进行求解

思路：

也是两个栈，一个栈存数据，一个栈存最小值。初始化的时候需要给辅助栈提前压入一个最大值。

反思：

再次写又犯了一个一模一样的错误，也就对于二次进栈的元素需要存，而不是只存一次。不然出栈的时候就会越界！！

class MinStack:

    def __init__(self):
        self.st1 = []
        self.st2 = []

    def push(self, val: int) -> None:
        # 一个就是数组栈，第二个就是保存的最小栈
        self.st1.append(val)
        if len(self.st2) == 0 or self.st2[-1] >= val:
            self.st2.append(val) 

    def pop(self) -> None:
        num = self.st1[-1]
        self.st1.pop()
        if len(self.st2) and self.st2[-1] >= num:
            self.st2.pop()

    def top(self) -> int:
        return self.st1[-1]

    def getMin(self) -> int:
        return self.st2[-1]

Leetcode 946 验证栈序列 mid

这个题目是用来模拟

class Solution:
    def validateStackSequences(self, pushed: List[int], popped: List[int]) -> bool:
        n = len(pushed)
        stack = []
        idx = 0
        for i in range(n):
            stack.append(pushed[i])

            while len(stack) and stack[-1] == popped[idx]:
                idx += 1
                stack.pop()
        
        if len(stack) == 0:
            return True
        return False

Leetcode 31 下一个排列 mid

题目意思：下一个排列就是字典序最小的。

技巧，看的0x3f的说的很好。就是一个数学问题，从想想13999的下一个数字如何去找。

右边往左边：找到相邻的两个数字中，右边小于右=左边的，

右边往左边：找到最小的大于其的数字进行交换。

然后对于该数字右边的进行反转。

class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;
        while(i >= 0 && nums[i] >= nums[i + 1]) i--;
        // 说明可以找到
        if (i >= 0) {
            int j = n - 1;
            //从右边往左边找最小大于的数
            while(nums[j] <= nums[i]) {
                j--;
            }
            swap(nums[i], nums[j]);
        }
        sort(nums.begin() + i + 1, nums.end());
    }
};
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        i =  n - 2
        # 从右往左找到第一个最小的，这里注意如果全部都是降序，说明下一个字典序要从头开始，直接跳过第二部找最小的，直接进行反转。
        while i >= 0:
            if nums[i] < nums[i + 1]:
                break
            i -= 1
        # 再去找右边最小大于他的数字
        j = n - 1
        while j > i and i >= 0:
            if nums[j] > nums[i]:
                nums[i], nums[j] = nums[j], nums[i]
                break
            j -= 1
        # 反转后面的数组，因为后面已经是降序，反转变成最小的
        i += 1
        j = n - 1
        while i < j:
            nums[i], nums[j] = nums[j], nums[i]
            i += 1
            j -= 1

Leetcode 208 实现Trie 前缀树 mid

应用：

比如ide等自动补全，前缀匹配查询（IP路由表等）都是利用前缀树来进行构建，匹配效率非常高。

思路

因为是前缀匹配，可以使用多叉树的结构，每一个树上的节点都有一个26大小表+是否为结尾标记符，表中存下一个节点信息。

class Node:
    def __init__(self):
        self.son = {}
        self.end = False

class Trie:
    def __init__(self):
        self.root = Node()

    def insert(self, word: str) -> None:
        cur = self.root
        for s in word:
            if s not in cur.son:
                cur.son[s] = Node()
            cur = cur.son[s]
        cur.end = True

    def find(self, word):
        cur = self.root
        for s in word:
            if s not in cur.son:
                return -1
            cur = cur.son[s]
        if cur.end:
            return 2
        return 1

    def search(self, word: str) -> bool:
        ans = self.find(word)
        if ans == -1 or ans == 1:
            return False
        return True

    def startsWith(self, prefix: str) -> bool:
        ans = self.find(prefix)
        if ans == -1:
            return False
        return True

# obj = Trie()

CodeFun 4035 只出现一次的数字(异或)

自己的思路，就是用map.

注意直接取python中map不存在的数据会抛错。要用get()方法.

import sys

class Solution:
    def __init__(self, data):
        self.data = data
    

    def OneNum(self):
        mymap = dict()
        for i in self.data:
            temp = mymap.get(i)
            if temp != None:
                temp += 1
                mymap[i] = temp
            else:
                mymap[i] = 1

        for (k, v) in mymap.items():
            if v == 1:
                return k

if __name__ == "__main__":
    input = sys.stdin.read
    datas = input().split("\n")
    data = list(map(int, datas[0].split()))
    sol = Solution(data)
    print(sol.OneNum())

官方的思路是：

利用异或（XOR）操作的性质：（我的理解就是相同为0，不同为1l）

任意数与自身 XOR 后为 00，即 a⊕a=0；

任意数与 00 XOR 后为自身，即 a⊕0=a；

XOR 运算具有交换律和结合律。

快速交换两个数（不借助临时变量）

a = a ^ b
b = a ^ b  # 此时b变成了原来的a
a = a ^ b  # 此时a变成了原来的b

parity 检测（奇偶校验）：

遍历数组，将所有数 XOR 在一起，相同的数会被抵消，最后剩下的即为只出现一次的数（因为存在结合律，相同的数会抵消）

官方解法代码

import sys

class Solution:
    def __init__(self, data):
        self.data = data
    

    def OneNum(self):
        ans = 0
        for num in self.data:
            ans ^= num
        return ans

if __name__ == "__main__":
    input = sys.stdin.read
    datas = input().split("\n")
    data = list(map(int, datas[0].split()))
    sol = Solution(data)
    print(sol.OneNum())

Leetcode 461 汉明距离 easy （又是异或）

一开始想每一位都取出来比一下，但是这样很麻烦。

思路：（自己直接想出来了，牛逼)

发现只去统计不一样的位数，相同位数不管，直接用异或，异或运算后相同位数消失，不同位数为1，再统计为1的个数。

class Solution:  
    def hammingDistance(self, x: int, y: int) -> int:
        x = x ^ y
        ans = 0
        while x:
            temp = x % 2
            if temp == 1:
                ans += 1
            x = x // 2
        return ans

Leetcode hot 32 最长有效括号 hard 栈

本来是一道动态规划的题目，但是说实话真的没必要用动态规划。

看到这个题目的第一眼就想着用栈来实现，其实结果也是用栈来实现的。但是自己想的很简单，入栈的是（）的个数而不是下标，同时也无法实现连续的括号

思路：0x3f大神！

还是用栈来进行维护，栈中存放的是左括号的下标。同时用一个哨兵，哨兵的作用是用来计算全部抵消的场景和新的起点。（感觉也有贪心的想法在里面）

如果此时可以抵消，那么就抵消当前可以消除的左括号下标，并且更新一次长度。

如果栈中的元素只有一个且不是左括号，这就说明后面不可能和前面有关系了，于是更新红线来找后面是否有最大

class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        # 题目要求是连续，应该如何去操作
        stack = [-1] # 哨兵来充当红线
        ans = 0
        for i in range(n):
            if s[i] == "(":
                stack.append(i)
            elif len(stack) > 1:
                stack.pop()
                ans = max(ans, i - stack[-1])
            else:
                stack[0] = i
        return ans

Leetcode 378 有序矩阵中第k小的元素 mid 堆

这个题目还是第一眼就是用堆去做，毕竟第k小这个关键字直接想到了堆的做法。直接秒了

class Solution:
    def kthSmallest(self, matrix: List[List[int]], k: int) -> int:
        n, m = len(matrix), len(matrix[0])
        h = [matrix[i][j] for i in range(n) for j in range(m)]
        heapq.heapify(h)
        while k > 1:
            temp = heapq.heappop(h)
            k -= 1
        ans = heapq.heappop(h)
        return ans

Leetcode hot 49 字母异位词分组 mid 哈希

这个题目其实一开始想用ascii码来确定，但是这不正确。因为ac和bb的值是一样的但是这不是异位词。没想到是排序后确定key，因为sorted可以按照字典序进行排序，返回一个新的数组。

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        mmap = {}
        ans = []
        for s in strs:
            s_sort = ''.join(sorted(s))
            if mmap.get(s_sort) == None:
                mmap[s_sort] = [s]
            else:
                mmap[s_sort].append(s)
        ans = []
        for key in mmap:
            ans.append(mmap[key])
        return ans

Leetcode hot 48 旋转图像 mid 找规律

技巧题目：ox3f那是真的牛逼啊，进行一次90度的旋转：相当于是是对于矩阵做了一次转置+每行反转。这个真的难想到，感觉主要还是观察数据的规律。

class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n, m = len(matrix), len(matrix[0])
        # 矩阵进行一次转置
        for i in range(n):
            for j in range(i):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        # 对于每一行进行一次反转，这样最后的结果就是旋转的结果
        for row in matrix:
            row.reverse()

但是如果是旋转180度了，上下反转，左右也需要反转。

class Solution:
    def rotate(self, matrix) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        # 上下整体反转一次
        matrix.reverse()
        # 对于每一行进行一次反转，这样最后的结果就是旋转的结果
        for row in matrix:
            row.reverse()

Leetcode hot 54 螺旋矩阵 mid 找规律

题目的意思是按照顺时针进行数组返回，所以看着像螺旋样式。这个题目依然是技巧题，还是看的0x3f的思路。有点像走dfs的方法一样，判断什么时候转弯，然后不走重复的路线。

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        dr = [[0, 1], [1, 0], [0, -1], [-1, 0]]
        m, n = len(matrix), len(matrix[0])
        i = j = idx = 0
        ans = []
        for _ in range(m * n):
            ans.append(matrix[i][j])
            matrix[i][j] = None # 已经访问过的后续不可达 
            x, y = i + dr[idx][0], j + dr[idx][1]
            if x < 0 or x >= m or y < 0 or y >= n or matrix[x][y] == None:
                idx = (idx + 1) % 4
            i += dr[idx][0]
            j += dr[idx][1]
        return ans

Leetcode 287 Find the Duplicate Number（基环树）Find the Duplicate Number

这个题目是技巧题，但是做法和快慢指针很相似，这种做法绝对想不到，是基环树（数组看成一张有向图，条件是值域和索引范围要一致）

nums建树，索引作为节点值。重复出现的数一定入度为2形成环，其余的入度都是1.如何找环了？快慢指针，如何找到入口也就是这个题目的答案了，floyd判圈法

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        fast = 0
        slow = 0
        while True:
            fast = nums[nums[fast]]
            slow = nums[slow]
            if fast == slow:
                break
        head = 0
        while head != slow:
            head = nums[head]
            slow = nums[slow]
        return slow
