DP 是我在算法上花时间最多的一块。这一篇按状态定义的形态分类整理，而不是按题号：

  • 一维 DP——爬楼梯、打家劫舍、等差数列划分、乘积最大子数组
  • 子序列问题——最长递增子序列、最长公共子序列、编辑距离
  • 二维 DP——最小路径和、01 矩阵、最大正方形、不同路径、最长回文子串
  • 分割类问题——完全平方数、解码方式、单词拆分、填充书架、组合总和 IV
  • 背包问题——分割等和子集（01 背包）、零钱兑换（完全背包）

DP 的难点从来不是递推式，而是「dp[i] 到底表示什么」。

动态规划保存子问题的解，避免重复计算。解决动态规划问题的关键是找到状态转移方程，这样我们可以通过计算和储存子问题的解来求解最终问题（那么说出现重复和包含关系的时候就可以考虑）

背包问题：

0-1 背包：每个物品最多选一次，容量有限，从大到小遍历容量。不选（dp[j] 保持不变）或选（dp[j] = max(dp[j], dp[j-w] + v)）。为保证每个物品只选一次，容量必须从大到小遍历。

完全背包：每个物品无限用，容量从小到大遍历。这样在更新 dp[j] 时，dp[j-w] 可能已经包含了当前物品，从而实现重复选取。

Leetcode 70 爬楼梯 easy 一维

最简单的动态规划

int climbStairs(int n) {
    vector<int> dp(n + 1, 1);
    for (int i = 2; i <= n; ++i) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}

答案的递归转化方程思路和我一模一样，但是他就是给dp的数组多留出了一个空位，这样就不需要给第二个数组赋值（这样容易出错，上面的写法初始值给了两个，就代表第二个数不会作为temp参与到转化中，这样就是错的）

class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n + 1, 0);
        ans[1] = nums[0];
        for (int i = 2; i <= n ; i++) {
            ans[i] = max(ans[i - 1], ans[i - 2] + nums[i - 1]);
        }
        return ans[n];
    }
};

Leetcode 413 等差数列划分 mid 一维

转化条件+状态转移方程。dp表示以该元素结尾的等差数列的种类数。最后的答案是把所有的答案进行相加

class Solution {
public:
    int numberOfArithmeticSlices(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n + 1, 0);
        for (int i = 2; i < n; i++) {
            if ((nums[i] - nums[i - 1]) == (nums[i - 1] - nums[i -2])) {
                dp[i] = dp[i - 1] + 1;
            }
        }
        int res = 0;
        for (int x : dp) {
            res += x;
        }
        return res;
    }
};

            if nums[i] - nums[i-1] == nums[i-1] - nums[i-2]:
                dp[i] = max(dp[i], dp[i - 1] + 1)
        
        ans = 0
        for i in dp:
            ans += i
        return ans

Leetcode hot 300 最长递增子序列 mid 子序列问题

对于这种子序列的问题，第一种就是定义一个dp数组，其中dp[i]表示以i为结尾的子序列的性质，那么对于结果通常是需要全盘取最大。对于这个题目来说的话就是，dp[i]表示以i为结尾的上升子序列的长度

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        vector<int> dp(n, 0);
        dp[0] = 1;
        for (int i = 1; i < n; i++) {
            dp[i] = 1;
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        int ans = 0;
        for (int x : dp) {
            ans = max(ans, x);
        }
        return ans;
    }
};

    def lengthOfLIS(self, nums: List[int]) -> int:

        dp = [0 for _ in range(n + 1)]
        for i in range(n):
            dp[i] = 1
            for j in range(0, i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)

Leetcode hot 1143 最长公共子序列 mid 子序列问题

子序列问题的第二种思路，dp[i]表示到第i个为止子序列性质，不一定需要以i为结尾。为止的话就说明不需要遍历取最大值了。

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        n, m = len(text1), len(text2)
        dp = [[0 for _ in range(m + 1)] for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[n][m]

Leetcode hot 72 编辑距离 mid 二维dp

这个题目的思路和上面的最长公共子序列的思路很类似，但是又不是完全一样的。

思路：dp思考

dp[i][j]表示以i为结尾的word1转变为以j为结尾的word2所需要的最小步骤。

初始化：很显然当i或者j其中一个为0时，方案数为原来的数组的长度删除完。

递推方程：

当word1[i] == word2[j]时，说明相同，不需要进行操作，直接继承 dp[i][j] = dp[i - 1][j - 1]

当word1[i] != word2[j]时，说明不相同，那么就可以进行三种操作，删除==word1少一个，插入==word2少一个（因为插入也是要以word2为模板），替换==word1换 。于是 dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][ j - 1]) + 1

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n = len(word1)
        m = len(word2)
        dp = [[0 for i in range(m + 1)] for j in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = i
        for j in range(m + 1):
            dp[0][j] = j
        
        # dp的处理我的理解还是找最原始的定义式，从定义式出发
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][ j - 1]) + 1
        return dp[n][m]

Leetcode 64 最小路径和 mid 二维dp

二维dp的主要思路其实也是一样，只是多了很多复杂处理的边界逻辑。

第一个就是搞清楚dp[i][j]的表示意思。表示走到第i行j列的时候的的最小路径

第二个就是搞清楚状态转移方程的定义，应该就是从两种状态转移过来，从上一个状态的右边来，和从下面来。所以取得最小值就行。

class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<vector<int>> dp(n, vector<int>(m, 0));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (i == 0 && j == 0) {
                    dp[i][j] = grid[i][j];
                } else if (i == 0) {
                    dp[i][j] = dp[i][j - 1] + grid[i][j];
                } else if (j == 0) {
                    dp[i][j] = dp[i - 1][j] + grid[i][j];
                } else {
                    dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n-1][m-1];
    }
};

Leetcode 542 01矩阵 mid 二维

第一眼看到这个题目直接想到就是四个方向搜索，很适合bfs。但是这个搜索最差是O(m^2 n ^2)，哪怕是可以加一个二维的布尔数组进行过滤，复杂度也很高。

dp的思想是什么了：DP 的核心是两次扫描，分别从四个方向“递推”最小距离，避免重复计算（左上到右下，右下到左上，一次2个方向直接搞完）

tips:python初始化二维数组时记得留意行列的数值和原数组值得关系

class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        n, m = len(mat), len(mat[0])
        # 先初始化为无穷大
        dp = [[sys.maxsize for _ in range(m)] for _ in range(n)]
        # 从左上到右下
        for i in range(n):
            for j in range(m):
                if mat[i][j] == 0:
                    dp[i][j] = 0 
                else:
                    if i > 0:
                        dp[i][j] = min(dp[i][j], dp[i-1][j] + 1)
                    if j > 0:
                        dp[i][j] = min(dp[i][j], dp[i][j - 1] + 1)
        # 右下到左上
        for i in range(n - 1, -1, -1):
            for j in range(m - 1, -1, -1):
                if mat[i][j] != 0:
                    if i < n - 1:
                        dp[i][j] = min(dp[i][j], dp[i+1][j]+1)
                    if j < m - 1:
                        dp[i][j] = min(dp[i][j], dp[i][j+1]+1)
        return dp

Leetcode 221 最大正方形 mid 二维

leetcode101这一类问题的思路：对于在矩阵内搜索正方形或长方形的题型，一种常见的做法是定义一个二维dp 数组，其中dp[i][j] 表示满足题目条件的、以(i, j) 为右下角的正方形或者长方形的属性。

本题dp[i][j] 表示 以i,j为右下角，全由1构成得最大正方形的边长。（因为直接表示面积不太好）

如果当前位置是0，那么dp就是0。如果dp为1，那就是从i-1,j-1 i,j-1 i-1,j 三个取最小？可以去画个图，一定是最小的，因为三个值其在上一次推导过来的局部最大正方形，如果有比他小的，说明这边不是局部最大。那么全局不可能最大。所以每次都是取min

class Solution:
    def maximalSquare(self, matrix: List[List[str]]) -> int:
        n, m = len(matrix), len(matrix[0])
        dp = [[0 for _ in range(m + 1)] for _ in range(n + 1)]
        ans = 0
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if matrix[i - 1][j - 1] == "1":
                    dp[i][j] = min(dp[i-1][j-1], dp[i][j-1], dp[i-1][j]) + 1
                    ans = max(ans, dp[i][j])
        return ans ** 2

Leetcode 279 hot 完全平方数 mid 分割类问题

对于分割类型题，动态规划的状态转移方程通常并不依赖相邻的位置，而是依赖于满足分割条件的位置。

对于本题，dp[i]表示 和为 i 的完全平方数的最少数量。那么i其实依赖于 i - j ^2，因为只能拆分为完全平方数，很显然j的限制条件也出现了。这样就找到了状态转移的方程。

class Solution:
    def numSquares(self, n: int) -> int:
        # 怎么进行划分，dp[i]表示和为i的最少数量
        # dp[i] = dp[i - j * j] + dp[j*j] = min(dp[i - j * j] + 1)
        dp = [sys.maxsize] * (n + 1)
        dp[0] = 0
        for i in range(1, n + 1):
            for j in range(i + 1):
                if j * j <= i:
                    dp[i] = min(dp[i], 1 + dp[i - j*j])
                else:
                    break
        return dp[n]

Leetcode 91 解码方式 mid 分割类问题

Leetcode 101上的题解太复杂了，我觉得有点离开这个题目的意思了。下面是101题解，处理起来代码也复杂。

思路：因为解码设计到1-26，最多有两位，先定义dp[i]表示为解码到第i个字符的方式数。对于第i个字符的解码方式其实就2种，第一个自己单独解码，第二个就是和前面的数字组合起来解码。那么递归方程其实就是2种，第一个dp[i] += dp[i-1],dp[i] += dp[i-2]。因为是算的总的个数，所以不存在max和min。

class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        dp = [0 for _ in range(n + 1)]
        dp[0] = 1
        for i in range(1, n + 1):
            if s[i - 1] != "0" :
                dp[i] += dp[i - 1]
            if i > 1 and s[i - 2] != "0" and int(s[i-2:i]) < 27:
                dp[i] += dp[i - 2]
        return dp[n]

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        dp = [False for _ in range(n + 1)]
        dp[0] = True
        for i in range(1, n + 1):
            for word in wordDict:
                m = len(word)
                if i >= m and s[i - m : i] == word:
                    dp[i] = dp[i - m]
                    
                if dp[i]:
                    break
        return dp[n]

Leetcode 1105 填充书架 mid 分割类问题

动态规划加贪心：dp[i]表示放置第i本书的时候最小高度，那么很显然dp[0] = 0。

思路一（leetcode101）：那么对于放置前i本书的一个思路是可以放置在i-1书的后面，或者是单独起一行。

思路二（leetcode大神，也就是代码）：把最后一本书当作每一层书架的最后一个，遍历前面的书架看看是否还可以减少当前最小高度。那么也就是说可以放在一层就放，放不到放置上一层。

dp[i] = min(dp[i], dp[j] + h) ，取当前层数（放下了）或者从上一层+当前层过来（放不下）

class Solution:
    def minHeightShelves(self, books: List[List[int]], shelfWidth: int) -> int:
        n = len(books)
        dp = [1000000 for _ in range(n + 1)]
        dp[0] = 0
        for i in range(1, n + 1):
            w, h, j = 0, 0, i - 1
            while j >= 0:
                w += books[j][0]
                if w > shelfWidth:
                    break
                h = max(h, books[j][1])
                dp[i] = min(dp[i], dp[j] + h)
                j -= 1
        return dp[n]

Leetcode 377 组合总和IV mid 分割类

还是太菜了属于是，一开始dp的定义就是有点问题。我定义的dp是以i结尾的合为target的种数，找不到递归方程。思考一个题目大概10分钟不然就不要浪费时间了。

Leetcode101和力扣上有个大佬的思路都是一样的，其实就是处理为爬楼梯的变体。回顾一下爬楼梯，每次只能走1-2步，走到目标为n时有多少种方法。那么这个题目其实就是楼梯是啥了，就是target。然后每次走的步数其实就是从nums中选择。于是这个思路就非常清楚了。dp[i]其实就是走到数为i时的种类数。

class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        dp = [0 for _ in range(target + 1)]
        dp[0] = 1
        for i in range(1, target + 1):
            dp[i] = sum(dp[i - num] for num in nums if i >= num)
        return dp[target]

import sys

class Solution:
    def maxSubline(self, nums):
        n = len(nums)
        dpmax = [-sys.maxsize] *(n + 1)
        dpmin = [sys.maxsize -1] *(n + 1)
        dpmax[0] = 1
        dpmin[0] = 1
        # dpi表示以i结尾的乘积最大非空连续子数组
        for i in range(1, n + 1):
            dpmax[i] = max(nums[i-1], dpmin[i-1]*nums[i-1], dpmax[i-1]*nums[i-1])
            dpmin[i] = min(nums[i-1], dpmin[i-1]*nums[i-1], dpmax[i-1]*nums[i-1])
        ans = max(dpmax[1:])
        return ans

Leetcode 62 不同路径 mid 二维

在这个题目上为二维度的dp，还是要明确dp[i][j]的定义是什么？表示从左边或者上边走到i,j的路径和。

第二个就是转移方程，很显然这个题目的状态转移就是从左边或者上边更新过来的。

tips：二维dp问题一般都是需要对于边界进行单独处理的。

class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp (m, vector<int>(n, 0));
        for (int i = 0; i < m; i++) dp[i][0] = 1;
        for (int j = 0; j < n; j++) dp[0][j] = 1;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] += dp[i - 1][j];
                dp[i][j] += dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};

Leetcode hot 416 分割等和子集 mid 01背包问题

直接想分割为两个集合，从而判断不同的集合个数，这是np=p的误区，是解答不出来。

转而去思考等价于从数组中找元素组成总和的一半，那么剩下的就自然变成了另外一个集合。这样就可以转化为0-1背包的问题来做。(但是01背包的边界条件自己又不记得了)

思路：

dp[i,j]定义：表示从[0, n-1]中选择数，使其体积为target是否可以做到。（dp的定义错误表示为不超过taget，于是定义初始值的时候出现问题，导致解答不出来）

初始化：因为我这里i从1开始，所以第0层要分析一下什么时候为true，那就是体积刚好为第一个元素的时候。dp[0][num[0]] = True， i任意，但是体积为0也是一种方案数。

递推方程：dp[i][j] = dp[i - 1][j - nums[i]] or dp[i - 1][j] 拿 dp[i][j] = dp[i - 1][j] 不拿

01背包：如果拿就需要比较一下拿之后和拿之前哪一种收益更高，不拿就直接等于。

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        # 三种情况，个数不够分，和为奇数，最大值大于一半
        n = len(nums)
        if n < 2:
            return False
        s = sum(nums)
        if s % 2 != 0:
            return False
        target = s // 2
        maxnum = max(nums)
        if maxnum > target:
            return False
        # dp[i][j]表示从[0, n-1]中选择数，体积为target是否可以做到
        dp = [[False for i in range(target + 1)] for j in range(n)]
        # 初始值
        dp[0][nums[0]] = True
        # 递推方程
        for i in range(1, n):
            dp[i][0] = True # 体积为0也是一种方案
            for j in range(target + 1):
                # 拿
                if j >= nums[i]:
                    dp[i][j] = dp[i - 1][j - nums[i]] or dp[i - 1][j] # 有一种就行
                else:
                    # 不拿
                    dp[i][j] = dp[i - 1][j]
        return dp[n - 1][target]

Leetcode hot 5 最长回文子串 mid 二维dp

下面是自己琢磨出来的代码，思考不全面但是主体思路对的，只过了部分样例（其实就只需要改一下i的遍历顺序就直接ac了，因为0-n-1的时候i+1都是没有更新的，其余地方的思路都是正确的）。

思路是正确的：dp表示s中区间[i,j]是否为回文子串。先判断是不是回文子串（回文的特性正好符合dp中的状态转移的思路），然后再去看回文子串中最长的.

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        if n < 2:
            return s # 小于两个不可能为回文
        # dp表示s中区间[i,j]是否为回文子串。先判断是不是回文子串，然后再去看回文子串中最长的
        dp = [[False for i in range(n + 1)] for i in range(n + 1)]
        # 只有一个的话说明就是回文串
        for i in range(n + 1):
            dp[i][0] = True
        for i in range(0, n - 1):
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    if j - i < 2:
                        # 说明只有1-2个元素构成，不需要走首尾加的情况
                        dp[i][j] = True
                    else:
                        # 说明是多个元素
                        dp[i][j] = dp[i+1][j-1]

                    
        # 统计最大的下标志对应的情况
        maxLen, max_i, max_j = 0, 0, 0
        for i in range(0, n):
            for j in range(i, n):
                if dp[i][j]:
                    if j - i + 1 > maxLen:
                        maxLen = j - i + 1
                        max_i = i
                        max_j = j
        return s[max_i: max_j + 1]

看了题解才发现是自己的循环走的方向有错误，对于i取决于i+1的话就要逆序遍历啊，不然状态都是没有走过了。

class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        if n < 2:
            return s
        dp = [[False for i in range(n + 1)] for i in range(n + 1)]
        maxLen =  0
        ans = ""
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                if s[i] == s[j]:
                    # 只有1个或者2个
                    if j - i == 0 or j - i == 1:
                        dp[i][j] = True
                    # 大于两个走状态转移
                    if j - i >= 2:
                        dp[i][j] = dp[i + 1][j - 1]
                    # 更新最大值
                    if dp[i][j] and j - i + 1 > maxLen:
                        maxLen = j - i + 1
                        ans = s[i : i + maxLen]
        return ans
