贪心的核心就一句话：每一步都做当前最优的选择。它不保证全局最优，但在相当多的题目上有效——尤其是「先排序再比较」这一类。

这一篇收录了我做过的贪心题目，按题目整理思路和代码。区间类的题占了一大半，因为区间问题基本就是排序 + 维护一个标志位。

该类算法主要是大部分是使用排序后进行比较完成。

Leetcode 455 分饼干

基本的思路就是排序然后比较孩子和饼干的需求。

class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());
        int num = 0;
        for(int i = 0, j =0; i < g.size() && j < s.size();) {
            if (g[i] <= s[j]) {
                num++;
                i++;
            }
            j++;
        }
        return num;
    }
};

Leetcode 135 分糖果

这个贪心题目不能使用排序后比较，糖果分发过程要确保相邻的孩子存在次序关系。所以采用左右遍历来解决，左遍历的时候，更新右边的值。这是因为如果是更新左边的值，那么如果下一个值进行更新，先前的更新就不满足次序的，是无意义的。然后右遍历更新左边的值。两次更新后就可以确保所有相邻的都存在次序关系。

class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> temp(n, 1);
        for(int i = 0; i < n - 1; i++) {
            if(ratings[i] < ratings[i+1]) temp[i+1] = temp[i] + 1;
        }
        for(int i = n - 1; i >= 1; i--) {
            if(ratings[i-1] > ratings[i]) {
                temp[i-1] = max(temp[i]+1, temp[i-1]);
            }
        }
        int num = 0;
        for(int i = 0; i < n; i++) {
            num += temp[i];
        }
        return num;
    }
};

Leetcode 435 无重叠区间 mid （右端点）

这个题目的思路是对于区间进行排序。

一般区间排序的问题，不是排序左端点就是排序右端点，所以要结合题目的意思来做。一般都要设定一个信号位来进行检测。

class Solution {
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end(), [](vector<int> &a, vector<int> &b){
            return a[1] < b[1];
        });
        int removed = 0, prev_end = intervals[0][1];
        int n = intervals.size();
        for(int i = 1; i < n; i++) {
            if(intervals[i][0] < prev_end) removed++;
            else prev_end = intervals[i][1];
        }
        return removed;
    }
};

Leetcode 605 种花 easy

没有完全通过的思路，一开始这个题目的思路借鉴的分糖果的次序思路，然后一直有样例通不过。错误的代码如下

感觉自己思路还是没有完全打开，还是做不对。很气！！下面是错误的思路

class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int num = 0, len = flowerbed.size();
        for(int i = 0; i < len; i++) {
            if(i == 0 && flowerbed[i] == 0) {
                flowerbed[i] = 1;
                num++;
            }
            if(i != 0 && flowerbed[i - 1] == 0 && flowerbed[i] == 0) {
                flowerbed[i] = 1;
                num++;
            }
        }
        for(int i = len - 1; i >= 1; i--) {
            if(flowerbed[i] == 1 && flowerbed[i-1] == 1) {
                num--;
            }
        }
        if(num == n) return true;
        return false;
    }
};

其实最简单的方法就是比较该数的前面或者后面是不是都是空位，那么可以就插入。（注意这个地方和次序不一样，次序是左右两次遍历），为了方便在数据最前和最后都加一个0，其实思路非常的简单md。

class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        flowerbed.insert(flowerbed.begin(), 0);
        flowerbed.push_back(0);
        for(int i = 1; i + 1 < flowerbed.size(); i++) {
            if(flowerbed[i-1] == 0 && flowerbed[i] == 0 && flowerbed[i+1] == 0) {
                flowerbed[i] = 1;
                n--;
            }
        }
        return n <= 0;
    }
};

Leetcode 452 最小的箭射击气球mid

这个题目是自己第一个苦思冥想解决的贪心，虽然花费的时间很多但是很值得。其实是一个区间问题，找到区间之间重合的值就是需要的弓箭的数量。对于左区间进行排序，因为我们是从左往右找区间重合的。对于每两个区间存在的三种情况：在里面，交叉，不在里面。在里面直接更新标志位的左右就行，交叉只需要更新左区间，不重合就是需要额外的弓箭，并且更新标志位左右。（注意好边界）

class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        sort(points.begin(), points.end(), [](vector<int> &a, vector<int> &b){
            return a[0] < b[0];
        });
        int num = 1, left = points[0][0], right = points[0][1];
        for(int i = 1; i < points.size(); i++) {
            //在其中
            if(left <= points[i][0] && right > points[i][1]) {
                left = points[i][0];
                right = points[i][1];
            }
            //有交叉
            if(points[i][0] > left && points[i][0] < right && points[i][1] > right) {
                left = points[i][0];
            }
            //没有交叉
            if(points[i][0] > right) {
                num++;
                left = points[i][0];
                right = points[i][1];
            }
        }
        return num;
    }
};

Leetcode 763 划分字母区间 mid

这是一个字符串的贪心，主要是把字符串变为区间的事情需要仔细思考。每一个字母都有一个最后出现的位置，这个是重点，我们只需要比较每一个字母出现位置是否可以在一个区间内，就可以尽可能多的划分区间。也是常用的区间套路，st和end指针。

class Solution {
public:
    vector<int> partitionLabels(string s) {
        int last[26];
        int n = s.size();
        for (int i = 0; i < n; i++) last[s[i] - 'a'] = i;
        int st = 0, end = 0;
        vector<int> ans;
        for (int i = 0; i < n; i++) {
            //一直往后增加end的长度，如果发现一个a已经不是在这个end中了，说明是下一个区间的
            end = max(end, last[s[i] - 'a']);
            if (i == end) {
                ans.push_back(end - st + 1);
                st = end + 1;
            }
        }
        return ans;
    }
};

Leetcode 56 合并区间 （左端点）

区间问题，一般都是先排序，无非就是对左端点或者右边端点进行排序。然后进行答案的记录

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        int n = intervals.size();
        vector<vector<int>> ans;
        int left = intervals[0][0], right = intervals[0][1];
        for (int i = 1; i < n; i++) {
            int l = intervals[i][0], r = intervals[i][1];
            if (l > right) {
                ans.push_back({left, right});
                left = l;
                right = r;
            } 
            if (l <= right && r > right) right = r;
        }
        ans.push_back({left, right});
        return ans;
    }
};

Leetcode 54 跳跃游戏 mid

思路：

维护一个每次可以抵达最右边的距离，判断下标是否超过这个距离。如果超过说明不可达。如果最大距离大于数组长度说明可达。

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        n = len(nums)
        maxright = nums[0]
        for i in range(n):
            if i > maxright:
                return False
            if maxright >= n - 1:
                return True
            maxright = max(maxright, nums[i] + i)

Leetcode 121 买股票的最佳时机 easy

思路：贪心。对于每次买入来说，要确保当前价格最低，所以要维护一个最小值。对于卖出来说。每次算当前值和最低值的差值来更新最大收入。

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        minprice = 10010
        ans = 0
        for i in range(n):
            minprice = min(minprice, prices[i])
            ans = max(ans, prices[i] - minprice)
        return ans
