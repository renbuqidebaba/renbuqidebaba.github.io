链表题的特点是思路简单、指针容易写错。这一篇收录了我做过的链表题目：反转、k 个一组翻转、两两交换、旋转、合并 k 个升序链表、删除倒数第 N 个节点等。

写链表题我的习惯是先想清楚要不要 dummy 头节点——大部分涉及头节点变动的题，加个 dummy 能省掉一堆边界判断。

Leetcode 61 旋转链表

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (k == 0 || head == nullptr || head -> next == nullptr) return head;
        int n = 1;
        ListNode* temp = head;
        while (temp -> next != nullptr) {
            temp = temp -> next;
            n++;
        }
        int add = n - k %n;
        if (add == n ) return head;
        temp -> next = head;
        while(add--) temp = temp -> next;
        ListNode* ans = temp -> next;
        temp -> next = nullptr;
        return ans;
    }
};

Codefun 删除链表的倒数第N个结点

其实是一个很常见的问题，删除思路就是让一个节点先出发，但是注意一下临界条件（画图思考）

import sys

class ListNode:
    def __init__(self, val, nextNode=None):
        self.val = val
        self.nextNode = nextNode

class Solution:
    def __init__(self,n, head, k):
        self.n = n 
        self.head = head
        self.k = k
    
    def DeleteNode(self):
        fast = self.head
        slow = self.head
        while self.k > 0:
            fast = fast.nextNode
            self.k -= 1
        # 下面的边界条件还是需要把握的更加清楚
        while fast.nextNode != None:
            fast = fast.nextNode
            slow = slow.nextNode
        temp = slow.nextNode
        slow.nextNode = temp.nextNode
        return self.head.nextNode
 
if __name__ == "__main__":
    input = sys.stdin.read
    datas = input().split("\n")
    n = int(datas[0])
    head = ListNode(0) # 虚拟头节点
    data = list(map(int, datas[1].split()))
    k = int(datas[2])
    cur = head
    for i in range(0, n):
        temp = ListNode(data[i])
        cur.nextNode = temp
        cur = temp
    solution = Solution(n, head, k)
    newHead = solution.DeleteNode()
    while newHead != None:
        print(newHead.val, end = " ")
        newHead = newHead.nextNode

Leetcode hot 23 合并k个升序链表 hard

这个题目以前看答案的做法就是用堆。现在重新去看这个题目也是要用堆.

为啥想到会去使用堆了，其实还是因为每次都需要从候选的链表中取最小的，然后每个链表选取完后又很自然的过渡到下一个节点。

需要注意一点：一开始入堆的时候一定要确保链表不为空。

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
ListNode.__lt__ = lambda a, b : a.val < b.val
# ListNode.__lt__ = lambda a, b : a.val > b.val # 最大堆
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        dummy = cur = ListNode()
        h = [head for head in lists if head] # 不为空才入堆
        heapify(h)
        while h:
            node = heappop(h) # 取出目前最小的元素
            cur.next = node
            cur = cur.next
            if node.next: # 下一个不为空就可以继续入堆
                heappush(h, node.next)
        return dummy.next

Leetcode hot 206 反转链表 easy

思路还是很简单的。空节点和空指针需要注意区分。

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy, cur = None, head
        while cur:
            temp = cur.next
            cur.next = dummy
            dummy = cur
            cur = temp
        return dummy

Leetcode hot 25 k个一组翻转链表 hard

情况：

一次就ac出来了，每一个局部是反转链表。

思路：

首先统计一下总的长度，然后判断需要反转的次数。

开始反转需要注意几个细节：如何确定每一次反转的头在哪里，反转尾巴在哪里，如何和之前的拼接上？反转过程中存在一个指针记录反转后头的位置；反转后尾巴的位置也用一个指针记录；引入了哨兵节点就可以有头，用一个指针不断记录反转后的最后一个位置就是下一段的头。

然后剩下不用链表直接和反转的链表接上就行。

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        dummy = ListNode(next = head)
        cur, n = head, 0
        while cur:
            cur = cur.next
            n += 1
        num, cur = n // k, head
        # first保存每一段开头，last保存反转最后一个，ans串联
        first, last, ans = None, cur, dummy
        while num:
            for i in range(k):
                # 反转一起局部的元素
                temp = cur.next
                cur.next = first
                first = cur
                cur = temp
            ans.next = first 
            ans = last 
            last = cur 
            num -= 1
        # 接上不需要反转的
        ans.next = cur
        return dummy.next

Leetcode hot 27 两两交换链表中的节点 mid

这个题目自己的做法和

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        cur = head
        first = dummy = ListNode(next=head)
        n = 0
        while cur:
            n += 1
            cur = cur.next
        k = n // 2
        cur = head
        while k:
            node = cur.next
            temp = node.next
            node.next = cur
            cur.next = temp
            first.next = node
            first = cur
            cur = temp
            k -= 1
        return dummy.next

Leetcode hot 146 LRU缓存 mid（最近最少使用）

这次的运气就没有这么好了，没有直接ac，整体思路还是正确的：哈希+双向链表（插入删除都是0（1），还可以记录最近的访问次序）

在写题目的时候遇到了几个问题：

对于双向链表的插入和删除有点问题，还是不够熟练，脑袋里再想想构建的过程。（直接建立不同的node）

第二个就是对于put逻辑要思考清楚：存在了怎么操作，不存在超过，不存在没超过。（一定是先按照存不存在划分，踩坑两次）第三次终于想起来这个点了

不要一开始就在listnode里面赋值为dummy，dummy都还在定义，要先定义后使用，从右到左的。

对于变量的定义太坑了，python对于定义错的变量不给指出来的，会以为是新定义的变量导致代码错误（比如34行会写成value，但是前面定义的是val，所以尽量都一致），自己写代码的时候要留心！！！

class ListNode:
    def __init__(self, key = 0, value = 0, next = None, prev = None):
        self.key = key
        self.value = value
        self.prev = prev
        self.next = next

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.len = 0
        # 哈希表
        self.map = {}
        # 链表,这个哨兵节点的初始化没想到的
        self.dummy = ListNode()
        self.dummy.next = self.dummy
        self.dummy.prev = self.dummy
        

    def get(self, key: int) -> int:
        if self.map.get(key) == None:
            return -1
        else:
            node = self.map.get(key)
            value = node.value
            self.remove(node)
            self.pushNode(key, value)
            return value
        
    def put(self, key: int, value: int) -> None:
        if key in self.map:
            self.remove(self.map[key])
            self.len -= 1

        if self.len + 1 > self.capacity:
            self.remove(self.dummy.prev)
            self.len -= 1
        self.pushNode(key, value)
        self.len += 1

    # 删除节点
    def remove(self, node):
        preNode = node.prev
        nextNode = node.next
        preNode.next = nextNode
        nextNode.prev = preNode
        del self.map[node.key]
        del node
        

    # 头插，写的有点问题
    def pushNode(self, key, value):
        # 新节点
        node = ListNode(key, value, None, None)
        node.prev = self.dummy
        node.next = self.dummy.next
        self.dummy.next.prev = node
        self.dummy.next = node # dummy要和node联系起来
        self.map[key] = node

class LRUCache:
    def __init__(self, capacity):
        self.size = 0
        self.capacity = capacity
        self.dummy = ListNode()
        self.dummy.prev = self.dummy
        self.dummy.nxt = self.dummy
        self.mmap = {}
    
    # 一种是不存在插入，一种是存在修改值
    def put(self, key, value):
        cur_node = self.mmap.get(key)
        if cur_node:
            self.remove(cur_node)
        else:
            if self.size + 1 > self.capacity:
                self.remove(self.dummy.prev)
        self.insert(key, value)
    
    def get(self, key):
        cur_node = self.mmap.get(key)
        if cur_node:
            val = cur_node.val
            self.remove(cur_node)
            self.insert(key, val)
            return val
        else:
            return -1

    def remove(self, node):
        prevNode = node.prev
        nxtNode = node.nxt
        prevNode.nxt = nxtNode
        nxtNode.prev = prevNode
        del self.mmap[node.key]
        del node
        self.size -= 1
    
    def insert(self, key, value):
        # 链表存入
        node = ListNode(key, value)
        nxtNode = self.dummy.nxt
        self.dummy.nxt = node
        node.prev = self.dummy
        node.nxt = nxtNode
        nxtNode.prev = node
        # 数据
        self.mmap[key] = node
        self.size += 1

Leetcode 82 删除排序链表中的重复元素 II mid

思路：

利用哨兵节点，方便处理特殊情况。如果当前元素的后两个元素相等，说明进入重复阶段开始进行删除（删除条件为：有且值相等），如果不等就正常往下面迭代。

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(next=head)
        cur = dummy
        while cur.next and cur.next.next:
            val = cur.next.next.val
            if cur.next.val == val:
                # 说明后续两个元素相等，可以开始删除了,删除就是不显示在链表中了
                while cur.next and cur.next.val == val:
                    cur.next = cur.next.next
            else:
                cur = cur.next
        return dummy.next

Leetcode 142 Linked List Cycle IILinked List Cycle II

这个题目总结了两个题目，一个是找环，一个是找环的入口。

怎么判断是不是有环了？快慢指针：一个走2步，一个走一步。如果相遇，说明一定是有环的。

怎么判断入口的位置？用一个新的指针从头出发和slow一起走，相遇的时候就是入口。（Floyd判圈法）

数学证明（不好想，条件要想清楚才可以顺利推导）：设b为相遇时slow走过的路径，那么fast走了2b路径。设a为入口到环的距离，环长度为c。设slow和fast相遇时，fast从入环口开始多走了k个圈。有2b-b = kc 也是就 b = kc。slow在相遇的时候相对于入环口在环中走了d距离，d = b - a = kc - a。这意味着，slow再多走a的长度就到入环口了，虽然不知道a的长度，但是可以让另外一个指针也从头开始走，他们都走a的时候一定相遇！！于是就解开了。

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head == None:
            return None
        fast = head
        slow = head
        flag = 0
        # 判断是否有环
        while fast and fast.next:
            fast = fast.next.next
            slow = slow.next
            if fast == slow:
                flag = 1
                break
        if flag:
            cur = head
            while cur != slow:
                cur = cur.next
                slow = slow.next
            return cur
        return None
