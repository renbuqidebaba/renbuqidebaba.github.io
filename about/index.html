我在做什么

工程上，我现在专注 Agent Infra，继续把对系统原理的理解带到新的实践中。

研究中，我关注「怎么让大模型推理得更准、更有依据」——用知识图谱做结构化的知识支撑，用强化学习决定该走哪条语义路径，再让多个 Agent 分工协作，把推理过程拆开、互相校验。

日常写 Go 和 Python。喜欢琢磨底层原理，也喜欢自己开小项目把想法落地。这里会记录过去积累的后端知识，也会留下转向 Agent Infra 过程中的学习、尝试与思考。

工作之外，希望多去一些地方、多体验不同的生活，让人生不只有一种可能。
